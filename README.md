# مبارزة النيلوفر

لعبة مبارزة سحرة ثلاثية الأبعاد بساحة حجرية حقيقية: أربع سحرة (نار، جليد، ظل، برق)، مهارات حركية، صراع شعاع، وجولات. ضد الكمبيوتر أو أونلاين مع صاحبك بكود.

- **العب بالمتصفح:** صفحة GitHub Pages تبع المستودع، ثم «العب الآن»
- **أندرويد:** آخر APK من صفحة Releases (بيتبنى تلقائياً مع كل تعديل)
- **آيفون:** افتح اللعبة بـ Safari ← مشاركة ← Add to Home Screen

## التقنيات
Three.js (WebGL)، Supabase Realtime للأونلاين، Capacitor لتطبيق الأندرويد، GitHub Actions للبناء.

## الإعداد
- `config.js`: حط فيه Project URL و anon key تبع Supabase (لا تحط service_role أبداً).
- GitHub Pages: Settings ← Pages ← Deploy from a branch ← `main` / root.
